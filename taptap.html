《奇异生物研究所》TapTap 渠道隐私说明

提供者：BigCan。更新日期：2026年11月15日。本说明适用于 Android TapTap 渠道版本，其他渠道以其单独说明为准。

本地游戏进度

生物、资源与玩法进度保存在设备本地，由玩家主动保存。TapTap 登录不会自动上传、合并或替换本地存档。卸载或清除应用数据会移除本地数据。

可选平台服务与第三方 SDK

  • TapSDK 4.11.1（易玩〔上海〕网络科技有限公司）：提供可选 TapTap 登录及其核心服务。经同意初始化后，SDK 可能处理系统版本、设备型号、CPU、内存、网络类型、AndroidID等基础设备信息；玩家主动登录后，SDK 处理授权的账号标识及基本资料。本游戏不请求邮箱授权，不向自建服务器传输登录令牌。核心依赖包含 TapDB 组件，具体信息处理范围以其官方政策为准。TapSDK 隐私政策。
  • Dirichlet / TapADN SDK 5.3.3.0（上海艾得蒽数字科技有限公司及其关联方）：提供玩家主动选择的激励视频、广告效果监测和反作弊。SDK 可能处理网络/IP、设备基本信息与广告展示、点击和奖励验证事件。当前宿主关闭位置、电话状态、Wi-Fi/SSID/BSSID/MAC、传感器、外部存储、OAID、应用列表与 AndroidID 相关可选采集开关，关闭摇一摇交互，不主动申请相应设备权限。TapADN 隐私政策。

玩家选择

首次使用时可选择游客继续，不初始化上述 SDK。只有确认已满18周岁并同意启用服务后才开放本版本可选广告。观看、点击、播放结束本身不直接发奖，SDK 确认奖励有效后才由游戏规则结算。可在设置中的广告隐私选项撤回授权，停止后续广告请求并退出平台登录；已初始化 SDK 的进程级对象在应用重启后不再初始化。撤回不影响本地核心玩法。

未成年人及发布状态

本版本的广告同意选择不等同实名认证或防沉迷认证。公开提供 APK 测试/下载前需按平台要求另行完成相应接入与审核，本说明不代表已通过平台审核。

联系与数据请求

对本说明或个人信息处理有疑问，可通过 游戏 TapTap 页面联系开发者。请勿在公开反馈中提交账号令牌、身份证或其他敏感资料。第三方平台账号数据请求也可通过各 SDK 官方政策中的渠道联系对应服务方。
